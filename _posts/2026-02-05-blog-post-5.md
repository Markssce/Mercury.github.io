# 1.  安装g++程序

先在终端输入：
```
g++ --version
```

如果终端提示要下载再下载；

方法一：下载Xcode
在App Store里下载 Xcode，其中集合了一系列的命令行工具；但是缺点是要占12G。（很大！）

方法二：单独下载(推荐)
进入网址，选择下图，进行安装。
https://developer.apple.com/download/all/

# 3.  运行C++程序

- 这里我提供一个简单的示例程序，输出"Hello，C++!"

```cpp
#include <iostream>
using namespace std;

int main() {
cout << "Hello, C++!" << endl;
return 0;
}
```

- 使用VS code打开存放代码的文件夹，新建一个文件，比如这里我命名为："hellocpp.cpp"，注意尾缀。

- 使用快捷键：⌘+⇧+B，或者点击顶端的终端，点击运行生成任务。

![[截屏2026-02-05 16.12.59.png]]
![[Pasted image 20260205161655.png]]
- 这里出现选项，点击第二个“clang++ 生成活动文件”
- 我们注意到这时文件夹里新生成了一个文件夹和同名的二进制文件。

- 在终端里输入
```bash
./hellocpp
```
即可运行。
